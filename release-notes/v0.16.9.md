# Profer v0.16.9

## 新功能

- Agent 执行链已默认切换到新的宿主无关 Runtime；普通桌面发送默认经过 `AgentRuntimeCoordinator`，显式设置桌面 runtime 回退值为 `0` 可临时回到旧编排器。
- 新增 Electron host adapter、运行时选择与状态投影，统一 Claude/Pi 生命周期、权限、取消、重试、后台任务和工具装配边界。
- 新增 Office 文档引擎包，支持 DOCX、PPTX、XLSX 的布局与拓扑解析。
- Agent 模式支持「修改重发」：任意历史用户消息都可改后重发，回退到该轮并恢复工作区文件（对齐 Chat 模式的编辑后重发）。

## 优化

- Pi 请求代理、Codex 标题生成、模型目录、Skill 资源和产品工具桥接完成收口。
- 增加 runtime/provider 隔离构建、无 Electron 加载、包边界检查和生命周期测试。
- 输入区 Composer 宿主 API 按领域收敛，减少组件对扁平 Electron API 的直接依赖。

## 修复

- 修复会话导航索引与渲染层分组口径不一致。
- 修复工作区热力图查询错误接纳团队工作区。
- 修复模型选择 Composer facade 迁移后的交互与测试夹具问题。
- 修复 Pi 请求代理跨 workspace 的 `undici` 类型冲突。

## 升级提示

- 本版本包含 Agent 执行链的内部架构收口。Electron 仍是当前桌面宿主，后续将继续用 headless host 验证跨宿主复用。
- Windows PowerShell 专用测试需在 Windows 主机执行；本机 macOS 验证跳过 4 项 Windows 专用测试。
