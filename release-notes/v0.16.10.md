# Profer v0.16.10

## 修复

- 修复 Agent 会话事件的宿主路由键：统一使用 agent 会话 id，不再从内核原生会话 id 推断。此前 `sdk_message` 会在 EventBus 转发层查不到绑定而被静默丢弃，表现为 UI 失去逐字出流、终态与刷新回放一起丢。
- 修复 headless 运行的桌面终态回执缺失：`run_complete` / `run_error` 现在同时走 EventBus 与 renderer 专用通道；运行中刷新时不再跳过已结束但有 backlog 的会话。
- 修复 Agent 消息持久化口径：只把用户可见转录写入历史，内部流控制消息仅实时投影，并补齐 `_createdAt` / `_channelModelId` / `_durationMs` 归一化。

## 优化

- 桌面 runtime 开关改为**显式 opt-in**：只有显式设为 `1` 才走新的宿主无关 Runtime，缺省与 `0` 均回到旧编排器，便于发布后止损。
- 矮窗口下输入框紧凑档空内容高度由 101px 调整为 81px。

## 新增

- 设置新增「用户消息位置」（左 / 右）。
- 设置新增「文件预览打开方式」：独立标签页（默认）或与对话左右分屏；分屏模式下用户主动打开预览会与会话并排，自动预览推送仍保持「只在正看着该会话时跟随」。

## 调整

- Agent 不再读取系统剪贴板，仅保留写入能力；相关 Pi / Claude 工具桥接、能力组清单与压缩描述同步清理。

## 升级提示

- macOS 仍为 `darwin-arm64` 无签名、无公证验收包；Intel、Developer ID 与公证未完成。
- Windows PowerShell 专用测试需在 Windows 主机执行；本机 macOS 验证跳过相关 Windows 专用测试。
