# Profer v0.16.14

## 修复

- **检查更新「无限转圈」**：`electron-updater` 6.8.9 的请求没有任何超时，连接建立后对方不回数据（代理半开、CDN 卡住、丢包不回 RST）时 `checkForUpdates()` 既不 resolve 也不 reject，界面永久停在「正在检查」，in-flight 锁也永不释放。现在每个源的元数据检查封 12s、整轮封 25s 硬顶，超时收敛成可重试的错误；in-flight 任务带时间戳，超过 60s 允许新检查接管；检查不再等待下载（下载转后台，45s 无进度判停滞）；被放弃的轮次会同时清掉 `electron-updater` 内部缓存的 promise——不清的话一次挂死之后每次检查都只会超时，必须重启应用。
- **同一轮出现两个模型头像**：流式期间插入的不可见 system 记录、或同一轮里模型 id 变了（`global:` / `cn:` 前缀差异）都会把 turn 拆成碎片。现在同一用户轮次内的相邻助手块一律合并，头像取首条消息的模型；真正的用户输入、可见分隔条（压缩边界 / 审批拒绝 / 压缩跳过）、后台任务唤醒的新轮仍会正常拆开。历史还在加载时先画不带头像的运行行，加载完成后不再补画第二个头像。
- **设置弹窗外的遮罩周期性闪动**：整窗 `backdrop-blur` 会让背景里任何重绘（侧栏相对时间刷新、积分条轮询）触发整张背景纹理重新采样。移除模糊层，靠提高遮罩不透明度补回聚焦感。
- **侧栏会话列表的滚动条压住行内容**：`scrollbar-width: thin` 会让 Chromium 走 Fluent overlay 滚动条，不占布局空间且忽略 `::-webkit-scrollbar` 宽度。改回 `auto` + `scrollbar-gutter: stable`，把滚动条放进侧栏自身留白，内容宽度不变。
- **远程连接**：手动 `?token=` 连接在公网 TLS 升级时被误断开；端口被占时自动顺延并兜住启动异常。

## 优化

- **Windows 侧栏顶到窗口上沿**：侧栏列表顶边原本恒对齐 Tab 标签下沿，那段留白是给 macOS 红绿灯用的。Windows 顶部没有红绿灯，现在直接顶到窗口上沿，与主区分段控件横竖对齐。
- **rail 图标统一 36px**：按钮 34→36px、图标 17→19px、头像 26→28px，顶部留白按 `8 + (40 - 36) / 2` 重算；置顶标记由实心星号改为大头针。
- **远程连接支持手动配置公网地址**：可手填公网地址并写入配对二维码，端口冲突时自动顺延。

## 升级提示

- macOS 仍为 `darwin-arm64` 无签名（ad-hoc）、无公证验收包；从浏览器直接下载 DMG 首次安装仍会被 Gatekeeper 拦。
