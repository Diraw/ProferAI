# Profer v0.16.11

## 新增

- **存储用量纳入文件检查点**：Pi 每轮编辑前的基线快照此前完全不在统计范围，`du ~/.profer` 与设置页数字能差出几个 GB。现在「存储用量」新增「文件检查点」分类，复制引擎按清单体积计、git 引擎的共享仓库单独精确统计，中断残留按实际占用兜底。
- **回收已归档会话的检查点**：归档只做收纳、不释放空间，这块占用最大的往往是「已归档但还活着」的会话。清理拆成「孤儿目录」与「已归档会话」两个互不重叠的范围，后者需要单独点击确认，删除后这些会话仍可打开继续对话，但不能再把文件回退到更早轮次。
- **自动归档增加工作区保留名额**：每个工作区按最后活跃时间保留最近 N 个会话（默认 3，0 = 关闭），保留名额不参与超时归档；置顶、草稿、运行中/分叉中、任务图仍有未完成节点的会话逐条豁免。
- **消息迷你地图按对话轮导航**：从按消息条数改为按轮回跳转。
- **分屏页原生关闭浮标**：分屏右栏网页的关闭入口改由主进程在原生视图上绘制，避免出现两个关闭按钮；页内新开页会接管原分屏位置，不抢对侧会话。
- **Pocket 远程能力补齐**：用户消息在落盘后进入事件流，移动端不再只能看到助手回复；新增工具列表/开关、附件保存等远程命令，工具信息只下发开关与说明，不暴露凭据与执行器配置。
- **Pocket 有界思考预览**：移动端可以显示思考过程，partial 帧只带尾部 800 字符、final 帧 2000 字符（均保留结尾），避免每 60ms 重发全文。

## 修复

- **Pi 上下文压缩系列**：
  - 历史图片按新旧分层压缩（最近 2 张高清、其余低清，总 base64 预算 6MB），覆盖恢复会话后的首轮与工具续轮。
  - 工具结果除单条 8k 截断外增加 20 万字符聚合预算，同一条助手回复派生的并行工具结果算一组；超预算的旧组原文落盘，消息里只留路径与 2k 预览，模型可按需读回。
  - 手动压缩加三类前置守卫（轮次过少、上一次未返回、5 分钟内连续压缩熔断），不再白烧摘要调用。
  - 只读工具改回全局并行调度（实测 3 个 200ms 工具 613ms → 204ms），写工具保持串行；`write` 增加读前校验，避免静默覆盖用户在编辑器里的改动。
- **自动标题失败可诊断**：失败返回结构化原因（状态码 + 响应片段），不再静默写回「首条消息前 20 字」伪装成功；兼容网关忽略 `stream:false` 返回 SSE 的情况，标题 Base URL 复用主链路端点归一化，修复「聊天正常、标题失败」。自动标题也不再阻塞轮次结束。
- **第三方 Gemini 网关兼容**：兼容非官方网关的目录结构与端点形态。
- **Agent 预览**：截图返回真实 mediaType（此前类型标错会导致渲染失败），预览文本上限降到 50k；导航预览清洗内部上下文块。
- **侧栏**：修复经典皮肤侧栏底色与迷你地图指示器；统一侧栏字号层级；置顶会话改为项目内优先排序。
- **Claude**：删除无效的 `toolUseConcurrency` 选项。

## 安全

- 发布脚本改为强制环境变量，去掉仓库内的主机/用户/端口默认值；`ssh`/`scp` 统一 `StrictHostKeyChecking=yes`。
- 配置目录权限收紧到 0700，`device.json` 与 `remote-token.json` 到 0600；`.gitignore` 覆盖 `.env.*`；清理文档、默认 Skill 与测试夹具中的开发机绝对路径。

## 重构

- 抽出 `edition-contract` 并把商业装配点收敛到唯一入口；新增 `@profer/session-store` 并接入 Electron 宿主。
- 移除未使用的 PPT 风格包与版式引擎、未引用的旧组件与项目指令遗留实现。
- 修正打包 workspace 排除作用域，兼容本地自签名。

## 升级提示

- macOS 仍为 `darwin-arm64` 无签名（ad-hoc）、无公证验收包；Intel、Developer ID 与公证均未完成，从浏览器直接下载 DMG 首次安装仍会被 Gatekeeper 拦。
- Windows PowerShell 专用测试需在 Windows 主机执行；本机 macOS 验证跳过相关 Windows 专用测试。
