# Profer v0.16.13-internal.1

## 新增

- **手写笔书写板**：输入框内嵌书写板，落笔即展开、卡片自然长高，工具栏与编辑器原地不动。带压感笔迹（Chaikin 平滑 + 压力变宽），点按不计入书写，空置 6 秒自动收起；抬手空闲 0.9 秒后识别成文字插到光标处，认不出只提示，不再往输入框塞图片附件。识别只用系统自带能力：macOS Vision、Windows `Windows.Media.Ocr`，不引入第三方 OCR 依赖。笔设备判定不依赖 `pointerType`——pen 类型，或 mouse 类型且压力偏离 0.5（Wacom 在 macOS 上即如此）。
- **推理档位按模型能力收窄**：同一个产品档位在不同模型上会编码成不同的 provider 值（DeepSeek V4 Pro 的「轻度」实际发 high），旧界面只显示档位名，用户无法判断自己选的档位到底发了什么。现在 capability 增加 `effortMap`，界面同时显示「所选档位 → 实际请求强度」；档位按模型真实能力渲染而不是固定七档，同名模型换后端后也不会再给出会被服务端直接拒绝的档位。模型切换与档位调整收进同一个面板，文案统一为轻度 / 中度 / 深度 / 极限。
- **委派子会话运行状态栏**：子会话页新增分支图标 + 状态 + 每秒计时，实时流状态优先（能给出准确起点、驱动计时）、持久化 status 兜底（只说明状态，不臆造起点）；运行超过 10 分钟且 `updatedAt` 不再前进时不再伪装成运行中。
- **首次引导与界面导览重做**：统一深色舞台与 1440px 栅格，功能导览改为 6 页「文案 + 界面缩影」并取消自动翻页，教程横幅改成三条可点上手路径，教程正文重写为快速上手 + 可复制任务；收尾改为居中完成卡片，提供「开始使用」和「再看一遍」两个出口。设置新增「首次引导 · 重新播放」。

## 优化

- **侧栏改为常驻 rail**：54px rail 承担全部全局导航（模式切换、Todo / 日程 / 定时任务、Agent 技能、插件、余额与设置），列表只负责会话与搜索；收起态没有列表，新建与搜索仍留在 rail 上。规划中心拆成三个并列入口，共享 `activeView='planning'`，选中态按分区判断，键盘左右切换能落到具体分区。侧栏宽度语义从「外壳总宽」改成「列表宽」，storage key 升到 v2，拖拽范围 230–360，老用户的 300 不会变成 354。
- **平滑滚动增加滚轮采样与诊断**：引擎每次滚轮事件吐出 Δy、deltaMode、事件间隔、手势判定、是否真正接管、命中的容器摘要、上一段动画的平均帧间隔与慢帧数，写入环形缓冲；设置页「对话浏览」下新增可折叠的「滚动诊断」，用于区分「没安装 / 被判定为触控板 / 容器没命中 / 接管了但主线程掉帧」。
- **对话区滚动条与进度条**改为滚动时才显示。

## 修复

- **平滑滚动在 Windows 上「完全没变化」**：自带平滑滚动的鼠标驱动（Logitech 等）与触控板发出的都是小增量，被判定成像素级输入后直通原生。新增 `smoothScrollForceEnabled` 开关，打开后像素级输入也走弹簧（`PIXEL_STIFFNESS=1800` 的更硬曲线、跳过速度加速），设置页诊断在 Windows 下始终可见并显示「像素·强制」判定。
- **委派子会话说一句话出现两个模型头像**：流式兜底气泡只在本轮还没画过任何内容时才带头像；实时消息与持久化副本对象身份对不上时「过程区一直折叠、看不出在运行」的问题一并修掉。
- **引导卡片落在窗口拖拽区**导致关闭按钮上半部分不可点击。

## 重构

- **移除开放认识论开关**：两套姿态让提示词分层、policy 与设置同步都要分叉，姿态本身固化进唯一的表达契约。Claude 端稳定沿用 `claude_code` preset，Profer 只追加本轮按能力与策略组装的 prompt；设置层的 `openEpistemicModeEnabled` 一并下线，旧配置文件与旧客户端带的该字段读取时丢弃、更新时剔除，不再重新持久化。
- **皮肤契约补分层文档**：新增 `references/layering.md` 说明层级、值格式（Tailwind 映射 token 只收三元组，`skin-base.css` 直连 token 收完整 CSS 值）、级联顺序与失败模式；修正「token 未定义即回落默认」的错误说法——直连 token 未定义会变成 guaranteed-invalid，按 unset 处理，通常就是透明。`SKILL.md` 升到 1.2.0。

## 升级提示

- 开放认识论开关已下线：旧配置里的该字段会被丢弃，不再写回。
- macOS 仍为 `darwin-arm64` 无签名（ad-hoc）、无公证验收包；Intel、Developer ID 与公证均未完成，从浏览器直接下载 DMG 首次安装仍会被 Gatekeeper 拦。
